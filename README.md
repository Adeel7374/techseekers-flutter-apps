# Tech Seekers — Flutter Apps (Concept Work)

Flutter apps built by Muhammad Adeel Riaz (Tech Seekers) as portfolio
concept work. Every app in this repo is a **fictional demo for a
fictional business** — none of these is a real client project, and no
business name, menu, price or booking in them is a real business fact.

## Apps

- `restaurant-ordering/` — **The Northern Fork**: fictional Manchester
  restaurant ordering app. Menu by category, basket, pickup/delivery,
  confirmation. Verified: `flutter analyze` clean, widget test passes,
  web build passes.
- `booking-app/` — **Glow Studio**: fictional Manchester salon booking
  app. Service, day and time-slot selection, booking confirmation.
  Verified: `flutter analyze` clean, widget test passes, web build
  passes.

## Run

```sh
cd restaurant-ordering   # or booking-app
flutter pub get
flutter run -d chrome
```

Built with Flutter. Each app is a single-codebase Android + iOS app.
